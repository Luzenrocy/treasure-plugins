# Treasure 宿主验收记录

由用户在 Treasure 宿主中填写；代理不执行宿主测试。

## 本轮重点验收

1. 导入 `build-output/excalidraw.zip`，确认插件注册成功；设置页中的“素材库”参数类型应为文本输入，不应出现 `string` 校验错误。
2. 打开 Excalidraw，确认右上角 `UIOptions` 区域旁只有插件提供的“素材库”按钮；官方原生素材库按钮不可见。
3. 点击插件“素材库”按钮，确认画布不重载、不跳页，右侧浮层打开；浮层可在“素材库”和“绘图目录”之间切换。
4. 关闭浮层后确认画布仍保持原场景、缩放、选择和撤销/重做状态。
5. 在窄窗口重复第 2–4 步，确认按钮可聚焦、浮层不产生页面横向滚动。
6. 素材库加载时若官方站点跨域受限，应显示“已切换到官方 GitHub 镜像”，并仍能看到目录；安装素材时确认下载和画布插入正常。

验收失败时请记录 Treasure 宿主版本、插件包路径、截图和浏览器控制台错误；尤其需要区分旧插件包缓存与最新 `build-output/excalidraw.zip`。
