# Durable memory

- Final deliverable is a technical solution, not a task plan.
- Preserve official Excalidraw canvas behavior; customize only the requested entry points.
- `UIOptions` is a visibility/action configuration surface, not a general DOM extension API.
- Use `renderTopRightUI` (or an equivalent public host slot) for the custom 素材库 trigger; avoid hard-coding internal DOM except as a temporary compatibility fallback.
- Treasure SDK forbids absolute paths and exposes private plugin storage separately from user-authorized directories.
- Any uncertain host behavior must be labeled `[Open question]` or `[Assumption]` in the final artifact.
