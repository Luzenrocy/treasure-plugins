## 概述与目标

本功能为 Treasure 提供一个独立的 Excalidraw 绘图插件。插件复用 Excalidraw 的画布编辑体验，
并通过 Treasure SDK 管理用户选择的绘图目录、文件引用和导出目标。用户可以在本地目录中
查看、编辑、新建和删除绘图文件，从官方素材库安装并使用素材，将当前绘图导出为图片。

官方 Excalidraw 仓库将编辑器描述为无限画布的手绘风格白板，并列出图形、自由绘制、箭头、
撤销/重做、缩放/平移、图片、素材库和 PNG/SVG/剪贴板导出等能力；本规格以这些能力作为
范围候选，最终以用户确认的澄清和实现验证为准（来源：S-001）。

## 范围与非目标

### 范围

- 本地核心画布编辑：选择、矩形、椭圆、菱形、线、箭头、自由绘制、橡皮擦、文字、图片、
  颜色/线宽等编辑器核心能力，以嵌入的 Excalidraw 编辑器实际可用能力为准。
- 画布操作：撤销/重做、缩放、平移、选择和编辑元素。
- Treasure 绘图目录：配置目录、查看文件、打开文件、编辑并保存、新建文件、删除文件。
- 官方素材库：从用户提供的官方素材库地址浏览或触发安装，导入合法素材并在画布中使用。
- 图片导出：将当前绘图导出到用户选择的位置；具体格式与导出选项见待确认事项。
- 中文项目规格、计划、任务和验收文档。

### 非目标

- 实时多人协作、登录账户、云端同步、分享链接和 Excalidraw+ 服务。
- 将绘图目录的绝对路径写入插件数据库、设置或运行时状态。
- 依赖 Treasure 宿主内部 API、Tauri API 或手写底层桥接消息。
- 复制 excalidraw.com 的评审导航、云端产品模块或与本地绘图无关的营销内容。

## 用户角色与场景

### 用户角色

- **本地绘图用户**：在 Treasure 中创建、编辑、整理和导出个人绘图文件。
- **素材使用者**：从官方素材库选择并导入素材，在当前画布中重复使用。

### 用户场景 1：配置目录并打开绘图

1. 用户首次进入插件，选择或配置绘图目录。
2. 插件通过 Treasure SDK 建立目录授权并显示目录中的绘图文件列表。
3. 用户打开一个绘图文件，插件加载其场景并保持可编辑。
4. 用户保存后，文件写回配置目录；取消或失败时保留当前编辑内容并显示可恢复状态。

### 用户场景 2：新建、编辑和删除绘图

1. 用户点击新建，插件创建一个空白场景并要求用户确认文件名。
2. 用户使用核心画布工具绘图、撤销、重做、缩放和平移。
3. 用户显式保存或按确认的保存策略保存为绘图文件。
4. 用户删除文件时看到文件名和明确的确认操作；取消删除不改变目录内容。

### 用户场景 3：安装并使用官方素材

1. 用户打开素材库入口，查看官方素材库页面或可安装素材列表。
2. 用户选择安装/导入，插件下载并校验素材文件。
3. 插件将素材加入本地素材集合或当前会话，并允许用户在画布中插入。
4. 网络不可用、素材格式无效或用户取消时，当前画布和已安装素材不被破坏。

### 用户场景 4：导出绘图图片

1. 用户选择导出图片，选择导出格式、画布范围和目标位置（若这些选项被确认纳入）。
2. 插件从当前场景生成图片并通过 Treasure SDK 写入用户选择的目标文件。
3. 写入失败、用户取消或场景无可导出内容时，页面保留当前编辑状态并给出可理解的错误。

## 功能需求

### 核心编辑器

- **FR-001**：插件 MUST 在 Treasure 中提供独立的 Excalidraw 画布编辑区域，并保留本地核心编辑范围；不得引入实时协作、账户、分享链接或云端同步。
- **FR-002**：插件 MUST 支持已确认范围内的基本图形、线和箭头、自由绘制、橡皮擦、文字、图片、选择、撤销/重做、缩放和平移；未能由集成版本支持的工具 MUST 在规格和验收记录中明确标记。
- **FR-003**：插件 MUST 为画布提供空态、加载态、保存中、保存成功、读取失败和导出失败状态；状态展示不得破坏主画布布局。
- **FR-004**：插件 MUST 遵循 Treasure 宿主的可访问性和滚动边界要求，核心工具可通过键盘访问，并为图标按钮提供无障碍名称。

### 文件目录与生命周期

- **FR-005**：插件 MUST 通过 Treasure SDK 的目录选择、设置和目录授权能力配置一个绘图目录；绝对路径不得进入插件持久化数据。
- **FR-006**：插件 MUST 使用 SDK 返回的目录/文件引用列出目录内容，并仅展示支持的绘图文件；不支持或损坏的文件 MUST 显示可恢复的错误状态。
- **FR-007**：用户 MUST 能新建、打开、编辑、显式保存和删除绘图文件；删除 MUST 要求明确确认，取消删除 MUST 不修改文件。
- **FR-008**：插件 MUST 采用显式保存；切换文件、关闭插件或删除文件前发现未保存修改时 MUST 提示用户。目标文件已存在或被外部修改时 MUST 要求用户确认覆盖、另存或取消；不得静默丢失内容。
- **FR-009**：保存、读取和删除操作 MUST 检查每个 SDK `Result<T>`，并处理取消、未授权、无效引用和文件过大等错误。

### 官方素材库

- **FR-010**：插件 MUST 提供官方素材库入口，并支持将合法的 Excalidraw library 数据导入编辑器；素材库地址和协议变化不得导致页面静默失败。
- **FR-011**：插件 MUST 在导入前校验下载结果和素材格式；网络失败、用户取消、重复安装和格式错误 MUST 保留当前场景并显示恢复路径。
- **FR-012**：插件 MUST 将已安装素材持久保存到插件私有存储，并在重启后支持离线使用；用户 MUST 能删除已安装素材，更新或损坏时 MUST 保留可恢复状态。绘图文件不得写入远端绝对路径。

### 图片导出

- **FR-013**：插件 MUST 支持将当前绘图导出为用户选择位置的图片文件；PNG 与 SVG 作为首版基线格式。JPEG/WebP、透明背景、范围、倍率和剪贴板等高级选项在计划阶段确认（当前为 [Assumption]）。
- **FR-014**：导出 MUST 使用当前场景和用户选择的目标文件引用，不得构造绝对路径或覆盖未确认的目标文件。
- **FR-015**：导出失败、取消、场景无内容和图片资源缺失时，插件 MUST 保留当前编辑状态并提供可理解的错误。
- **FR-016**：若纳入透明背景、导出范围、倍率、JPEG/WebP 或剪贴板等选项，规格 MUST 为每个选项定义默认值和验收场景。

## 数据与文件模型

- **DrawingFile**：用户目录中的 Excalidraw 场景文件。推荐扩展名为 `.excalidraw`，其 JSON 结构和兼容版本必须以集成版本的官方恢复/序列化能力为准（[Open question]）。
- **DrawingDirectory**：由用户选择并经 Treasure SDK 授权的目录引用。插件只保存系统设置所需的授权标识或摘要，不保存绝对路径。
- **LibraryItem / LibraryBundle**：从官方素材库下载并经 Excalidraw library 解析能力验证的素材数据。保存位置和持久化策略待确认。
- **ExportTarget**：用户通过系统保存窗口选择的目标文件引用，仅用于本次写入，不持久化。

## 外部依赖与失败处理

- 插件 MUST 直接集成官方 `@excalidraw/excalidraw` 编辑器代码；Vue 页面通过适配层连接 Treasure SDK。构建产物兼容性、挂载生命周期和状态桥接在计划阶段确认，但不得改为远程 iframe 或自研画布替代。
- 官方素材库依赖网络访问；插件 MUST 提供加载、超时、不可达、取消和素材格式错误状态，并避免把远端内容当作可信本地文件。
- Treasure SDK 是宿主能力唯一入口。目录、文件和保存窗口操作都必须使用 SDK，并遵守 `Result<T>`、用户授权和单次读写限制。
- 文件格式解析失败、外部编辑覆盖、重复文件名和目录权限撤销必须保留可恢复的编辑状态，禁止静默丢失内容。

## 非功能要求

- **安全与隐私**：不持久化绝对路径；不执行远端素材中的脚本；不绕过宿主权限；导入和导出只处理用户明确选择的目标。
- **可访问性**：工具按钮、素材库入口、文件列表和确认弹窗必须具备键盘操作、焦点顺序和无障碍名称。
- **本地化**：本规格、计划、任务和验收文档使用简体中文；技术名词、API、命令、路径和标准模板标题可保留原文并提供中文说明。
- **可维护性**：插件保持独立目录，UI、画布状态、SDK 文件边界和导入导出适配层分离，避免修改其他插件。
- **可验证性**：核心绘图、文件 CRUD、素材导入、图片导出和失败恢复均有独立验收场景；宿主目录加载和 ZIP 导入须人工验证。

## 验收标准

- **SC-001**：用户能在 Treasure 中完成核心绘图场景：创建元素、编辑元素、撤销/重做、缩放/平移并保存为绘图文件。
- **SC-002**：用户能配置绘图目录，查看文件，打开并编辑文件，新建文件，删除文件；取消或失败操作不丢失当前编辑内容。
- **SC-003**：用户能从官方素材库完成至少一次安装/导入，并将素材插入当前画布；网络不可达和格式错误均有明确反馈。
- **SC-004**：用户能将当前绘图导出为已确认的图片格式并在系统目标位置打开；导出取消或失败不会破坏画布。
- **SC-005**：所有 SDK 调用都检查 `Result<T>`，绝对路径不进入插件持久化数据，未经确认的远端内容不会执行。
- **SC-006**：插件在 Treasure 宿主开发目录加载和打包导入路径均完成人工验证，并记录核心场景、权限、错误恢复和导出证据。

## 待确认事项

- **OQ-004**：图片导出是否支持 PNG、SVG、JPEG/WebP、透明背景、选区/全画布、倍率和剪贴板；默认值是什么。
- **OQ-005**：`.excalidraw` 文件是否作为唯一正式格式，是否允许导入/导出 `.excalidrawlib` 或其他兼容格式。
