# 持久决定

- `.gxp` 是观象谱的唯一原生、可编辑、多画布工作簿；`.smm/.xmind` 为只读输入，编辑转为新 `.gxp`。
- 本次校对的产品依据是 `prototype/README.md`，不是历史页面或早期研究稿。
- 正式工程的目录授权恢复依赖 SDK 2.1.1 的 `permissions.verifyDirectoryGrant`；仓库模板中 SDK 2.0.0 不足以实现指南所列的恢复流程。
- SDK 返回引用而非路径；不接触 Tauri/宿主源码/私有桥接。
- 文档必须区分“已实现的原型交互”“需实现的生产代码”“需要 PoC 才可承诺的格式能力”。
- `excalidraw` 同仓工程将 `treasure-sdk ^2.1.1` 与 `minPlatformVersion: 2.3.0` 组合；观象谱可以把 `2.3.0` 作为保守首版宿主基线，仍以目标宿主联调作为发布验收。
- 原型在折叠/展开时执行可撤销的 `markChanged`；本方案据此将折叠确定为内容态，写入 `.gxp`、修订与历史。
