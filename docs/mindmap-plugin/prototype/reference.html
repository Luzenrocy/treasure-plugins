最近操作：等待原型状态

上方工具与状态仅供研发观察。框内为产品界面；窄屏可横向滚动，建议以 1440 px 宽度查看。

交互契约：触发、退出、遮罩、焦点与互斥

每个场景都是一次独立加载。可在框内继续操作；重新选择场景或点击“重置该场景”会丢弃本次内存改动，恢复该场景。所有标注与说明均留在产品框外。

界面状态触发与退出遮罩与焦点互斥规则
节点选中单击节点选中；双击编辑标题；点击画布空白或 Esc 退出选区。不遮罩画布；选区显示轮廓和节点工具条。工具条跟随当前选区，默认态不常驻。
样式属性由选区样式入口打开；关闭按钮或 Esc 收起。侧栏不冻结整个工作台；关闭回到触发入口，入口不可用则回到画布。只编辑当前选区；切换选区同步属性。
目录/大纲悬停左侧短横标记展开，可切换文件与大纲；“更换工作目录”打开目录选择。悬浮面板覆盖画布，移出后收起；目录选择是独立模态抽屉。默认无整列占位及侧栏按钮。
导出顶栏导出打开；取消、关闭按钮、Esc 或允许的遮罩点击退出。模态遮罩；焦点停留于对话框，关闭回到触发入口，入口不可用则回到画布。仅提供 SVG 与 PNG；SMM/Xmind 为输入格式。导出不改变未保存状态。
未保存保护脏文档切文件、关闭、换目录时触发；保存/放弃后继续目标操作，取消留在原文件。模态遮罩；暂锁内容编辑，明确显示来源文件和离开目标。保护流程串行执行；取消不隐含放弃，保存完成后再继续离开。
文件删除目录文件菜单打开确认；发起前可取消。请求开始后等待结果。模态遮罩；删除中禁用取消与返回编辑，Esc 和遮罩不能解锁。固定目标文件；成功才移除列表项。节点 Delete 与文件删除分开。
外部预览SMM 与 Xmind 以只读预览打开；Xmind 预览前提示高级对象的呈现限制。预览允许缩放、切换已有画布、选中与导出；来源文件不进入内容编辑状态。保存禁用，外部来源不直接写回；不自动创建副本。
编辑副本点击“创建可编辑副本”或尝试编辑时触发；取消保留来源预览。确认后新建原生工作文件，再继续原编辑动作；新副本标记未保存。节点编辑、画布新增/改名、主题、结构、备注及撤销都适用复制保护。
空/异常目录空态新建或导入；异常态重试或重新选择目录。替换目录内容区，不额外遮住画布。目录异常不等于当前内存文档丢失。

Esc 按“当前可取消的浮层 → 属性/抽屉 → 选区”的优先级退出；删除请求已开始时不可取消。Tab / Enter 增加子节点 / 同级节点，双击改名，Ctrl / Cmd + S 保存，Ctrl / Cmd + Z 撤销。输入框与中文组合输入期间保留文字输入行为。

状态桥只接收当前 iframe 发出的 mindmap-prototype-state 消息；展示值通过纯文本写入。原型能力与模拟边界见 README。
