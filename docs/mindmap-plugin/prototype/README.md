# 观象谱交互原型

这是供产品评审与研发对照的浏览器原型。产品界面默认保持干净；场景工具、运行状态和交互说明放在独立研发参考页，不叠加到画布中。

- [纯产品入口](index.html)：默认工作台，可连续操作。
- [研发参考入口](reference.html)：选择一个可复现场景，观察当前浮层、选区、文件、未保存/保存/删除状态及最近操作；交互契约默认折叠。
- [校对后的技术与 UI 实施方案](../revisions/2026-11-06-technical-plan/technical-ui-proposal.md)：当前研发依据，以 SDK 2.2.0 CLI 创建的正式工程为约束。 [初版技术与 UI 方案](../technical-ui-proposal.md)保留为研究基线；正式标识见[观象谱命名决定](../revisions/2026-11-05-native-and-naming/decision.md)。

直接用浏览器打开 `index.html` 或 `reference.html` 即可，支持 `file://`，无需安装依赖，也没有 CDN、远程字体或外部网络请求。也可从仓库根目录运行：

```sh
python3 -m http.server 8765 --directory docs/mindmap-plugin/prototype
```

随后打开 [本机研发参考页](http://localhost:8765/reference.html)。桌面目标宽度为 1440 px，产品界面至少支持 900 px；参考页内嵌画布高 760 px，窄屏允许横向滚动。

## 复现场景

每次切换或重置场景都会重新加载 iframe，恢复该场景的独立初始状态，不在旧场景上叠加面板。也可直接给产品入口添加 `?scenario=...`。

| 场景 | 参数 | 可观察内容 |
| --- | --- | --- |
| [默认工作台](index.html?scenario=default) | `default` | 画布与左侧悬浮目录/大纲，无选区、属性栏或弹窗 |
| [选中节点](index.html?scenario=selected) | `selected` | 单一选区与上下文工具条 |
| [样式属性](index.html?scenario=style) | `style` | 选区对应的样式面板 |
| [更换目录抽屉](index.html?scenario=directory) | `directory` | 工作目录选择、使用此目录及关闭入口 |
| [导出](index.html?scenario=export) | `export` | 格式、范围、系统保存位置与浏览器备用下载 |
| [未保存保护](index.html?scenario=unsaved) | `unsaved` | 带具体离开目标的保存/放弃/取消分支 |
| [删除确认](index.html?scenario=delete) | `delete` | 固定文件目标与请求开始前的取消 |
| [删除中](index.html?scenario=deleting) | `deleting` | 取消/返回编辑禁用，等待模拟结果 |

## 操作与状态约定

可见功能按钮都应产生明确行为或反馈；未支持能力应给出解释，不能表现为静默成功。正常工作流从默认场景开始，场景入口用于直接审查中间状态。

- 单击节点选中；双击改名；画布获得焦点且有选区时，`Tab` 添加子节点、`Enter` 添加同级节点。输入框和中文组合输入保留文字输入行为。
- 点击“添加画布”后会立即进入新画布的名称编辑；已有画布可双击底部标签改名，`Enter` 或失焦确认，`Esc` 取消。
- `.smm`、`.xmind` 都是外部只读来源。切换已有外部文件会直接进入预览，不再因文件是 Xmind 而弹出笼统的“打开外部导图”确认；仅在用户主动点“兼容说明”时展示范围。可查看、缩放、切换已有画布及导出；点击“创建可编辑副本”，或从预览尝试修改内容时，先确认复制为新的原生工作文件。原文件不进入脏状态，不直接保存回原外部格式。副本可编辑节点、主题、结构、备注与画布，并支持保存、撤销；不再在新增第二张画布时才提示格式转换。新建空白文件也直接使用原生工作格式。
- 产品名称为**观象谱**，原生工作簿后缀为 **`.gxp`**。一份 `.gxp` 可包含一张或多张画布；默认样例“产品设计.gxp”是原生工作文件，“读书笔记.smm”和“项目规划.xmind”演示外部来源。SMM 与 Xmind 仅作输入格式，原型导出交付物仅提供 SVG 和 PNG。
- 画布不保留顶部标题栏。左上角仅保留主菜单，右上角提供保存与导出，中央浮动组提供撤销、重做、主题与结构；按钮采用 Excalidraw 式图标分组，文字仅通过悬停提示与无障碍标签提供。桌面左缘默认显示钉钉文档式缩略大纲：每个可见主题对应一条短横标记，层级以长度与实/虚线区分，当前主题加深；主题新增、删除或折叠时标记数量同步变化。鼠标移入该标记区时，以覆盖浮层展示完整大纲（可切换文件目录），移开后收起，且始终不压缩画布。画布左下角不另设大纲按钮。选中节点后，点击上下文工具条“样式”才展开属性。`directory` 场景演示更换工作目录，两者不叠加。

  根主题在左右布局下具有两个独立的折叠控制：右侧控制只收起右支，左侧控制只收起左支；向下布局使用底部的单一折叠控制。大纲与左缘缩略标记只显示当前可见分支。

  左侧大纲中，主题文字用于选中节点，前置箭头是独立的展开/折叠入口。

  文件与大纲是同一侧栏内的互斥内容视图，采用次级 Tab 而非操作按钮：两个等宽标签共享一条 1px 底部分隔线，选中项使用铺满整格的 2px 指示条，不使用卡片边框或选中填充。面板展开时层级高于左上角主菜单；目录底部不额外提供“新建思维导图”按钮。

  左上角主菜单用于文件与视图操作，不重复放置保存和导出；保存、导出始终只在右上角浮动组中出现。
- `Ctrl/Cmd + S` 保存，`Ctrl/Cmd + Z` 撤销。`Esc` 优先关闭当前可取消浮层，再收起属性/目录，最后退出选区。删除请求开始后，Esc、遮罩与取消均不能提前解锁。
- 文件列表单击切换。当前文件有改动时，先选择保存、放弃或取消；取消保留原文件和未保存状态，保存完成后才继续目标操作。
- 删除目录文件与删除画布节点为不同操作。文件删除固定目标，请求开始前可取消；开始后禁用取消与返回编辑，等待结果，成功后才移除列表项。
- “打开文件”与 `Ctrl/Cmd + O` 调起系统文件选择器，筛选 `.gxp`、`.smm`、`.xmind`；它不是工作目录的文件列表。导出点“导出”时调起系统“另存为”，多画布导出逐个选择目标文件。导出生成交付物，不清除当前文档的未保存状态。
- “重置视图”只恢复缩放与位置，不改变节点、不产生历史记录或未保存状态；“重置画布”保留中心主题、删除其余分支，保留当前缩放与位置，并作为可撤销的内容修改。
- 属性、抽屉和模态对话框按单一状态切换。模态关闭后恢复到仍可用的触发入口或画布；不会同时铺开所有演示面板。

## 模拟边界

文件列表、目录授权、保存、删除、兼容报告和工作簿会话使用内存数据模拟；刷新页面或重置场景会恢复样例。浏览器入口会使用系统文件选择器；选中的文件在原型中仍以同格式样例树展示，不解析真实内容。保存反馈表示内存会话已记录，不等于已写入磁盘。

宿主实现使用 [Treasure 文件适配器](treasure-file-adapter.ts)：它以 `files.openDialog → files.readFile` 打开外部文件，以 `files.saveDialog → files.writeFile` 将 SVG/PNG 写入用户在系统对话框中选定的位置。纯浏览器预览无法取得任意本机路径；若 `showSaveFilePicker` 不可用，会显示点击下载作为明确的备用路径。SMM 与 Xmind 不提供导出或覆盖写回。Xmind 二进制解析、真实目录权限、磁盘回收、完整 `.gxp` 包、复杂格式及高级语义兼容仍须由格式适配层与真实样本完成验证。

[文件通路回归记录](qa-host-file-flows.md)覆盖系统打开、无前置兼容弹窗、视图/内容边界与系统另存为桥接。

研发参考页通过 `postMessage` 观察产品状态：

```js
{
  type: 'mindmap-prototype-state',
  state: {
    scenario, overlay, inspector, selectedNodeId,
    fileName, dirty, saving, deleting, sheetName
  },
  event: '中文操作名'
}
```

接收端只接受当前 iframe 的 `event.source`，通过 `textContent` 渲染消息文本，不使用 `innerHTML`。该消息用于观察状态，不是宿主调用接口或文件持久化协议。

控制台提供 `window.__mindmapPrototype.getState()`、`failNext('save' | 'delete' | 'open')` 和 `reset(scenario)`，用于读取状态、注入下一次操作失败及恢复场景。它们仅供研发检查，不出现在产品工具栏中。
