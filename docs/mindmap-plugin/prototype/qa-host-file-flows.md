# 观象谱文件通路回归

日期：2026-11-05。验证环境：本机 headless Google Chrome、Playwright、`127.0.0.1:8787`，窗口 1440 × 900。

本轮以宿主桥接替身验证交互边界；实际 SDK 适配器另以 TypeScript 对仓库中 `treasure-sdk` 声明文件完成类型检查。替身不冒充 Xmind 解析器或真实磁盘写入。

| 场景 | 结果 |
| --- | --- |
| 默认工作簿 | 样例为 `产品设计.gxp` |
| 左侧悬浮面板 | 展开时层级高于左上角主菜单，且目录底部无新建按钮 |
| 主菜单 | 不含保存和导出；右上角保留唯一入口 |
| 左侧大纲箭头 | 独立折叠/展开当前主题；文字区域仍只选中主题 |
| 系统打开 | SDK 返回 `.xmind` 后直接进入只读预览，未出现前置兼容弹窗 |
| 兼容范围 | 只在用户点击“兼容说明”后打开 |
| 重置视图 | 缩放恢复至 100%，节点数、修订与脏状态不变 |
| 根主题右侧折叠 | 只收起右侧分支，左侧分支保持可见 |
| 重置画布 | 保留中心主题与当前视图，文档转为可撤销的脏修改 |
| 导出 | 桥接收到 SVG 字节和目标文件名，界面仅在返回已保存后显示成功，原文档状态不变 |

结果：10 项通过，无页面错误。脚本：`/private/tmp/mindmap-current-qa.cjs`。

宿主接线代码见 [treasure-file-adapter.ts](treasure-file-adapter.ts)：

- 打开：`files.openDialog` → `files.readFile`；
- 导出：逐个 `files.saveDialog` → `files.writeFile`；
- 用户取消选择时不替换当前文档、不把未写入的文件显示为已保存。
