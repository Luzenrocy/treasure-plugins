## 修复闭环

1. **编辑与 DOM 稳定性：**选中时重建 SVG 造成双击失败、失焦重绘造成首次保存/切文件点击丢失。保留相关节点后，用真实双击和直接点击路径复验通过。
2. **离开提交时序：**放弃过早回退内存，以及保存 N/N+1 的后续离开边界。延迟到离开真正成功才提交放弃，取消/打开失败与旧保存序列复验通过。
3. **焦点与窄屏布局：**浮层/属性重绘导致焦点落到 body，900 属性抽屉重复标题。稳定入口、主动聚焦与重绘保焦点后，Esc/关闭/主题卡复验通过；900 抽屉为单标题、单关闭图标及底部完成按钮。
