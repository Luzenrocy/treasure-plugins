# 观象谱

观象谱是 Treasure 的本地思维导图工作簿插件。它以 .gxp 作为唯一可编辑、可保存的原生格式；.smm 与 .xmind 仅用于只读预览，用户确认创建 .gxp 副本后才可编辑。

## 已实现的工作流

- 新建、打开、正常保存和另存为 .gxp 工作簿；
- 首次进入先选择工作目录；后续启动恢复目录授权、管理目录内 .gxp 列表及回收站删除；
- 多画布、主题树、折叠、结构切换、主题/备注、撤销与重做；
- .smm JSON 与含 content.json 的 .xmind 多画布只读导入；
- 外部文件创建可编辑 .gxp 副本，绝不覆盖来源；
- SVG、PNG 导出，导出不改变工作簿保存状态；
- 离开当前未保存工作簿时的保存、放弃、取消保护。

## 架构

src/domain.ts 定义工作簿和主题树；src/format.ts 负责版本化 .gxp 编解码及结构校验；src/external.ts 隔离外部格式解析；src/exporter.ts 生成 SVG/PNG。界面仅通过 treasure-sdk 提供的文件和目录引用访问宿主文件系统，不保存或显示绝对路径。

## 视觉

画布使用暖白背景 `#faf8f4`、交互紫 `#7656a7` 与细网点背景。界面没有固定顶部标题栏：左上为主菜单，右上为保存与导出，中央为撤销、重做、主题和结构的图标工具组。左缘缩略大纲展开为不压缩画布的悬浮侧栏；侧栏中的展开/收起仅服务于导航，不会改动导图内容，也不会触发外部文件副本流程。选中主题后才显示上下文工具条，点“样式”才打开属性面板。

节点与 SVG/PNG 导出共用同一套布局：根、一级主题和叶主题有独立样式，中文长标题自动换行；左右布局保留左右两支独立折叠控制，向下布局使用底部单一控制。画布支持平移、缩放、适应画布和重置视图。

## 开发与打包

    npm install
    npm run dev
    npm run typecheck
    npm test
    npm run build
    npm run build:plugin:zip

目录包和 ZIP 输出至 build-output/。在 Treasure 桌面宿主中注册调试插件后，需进一步验证系统文件对话框、目录授权恢复和回收站行为。
